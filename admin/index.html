🔑 Connect GitHub

Enter a GitHub Personal Access Token with actions:write scope to trigger pipeline runs.

🔒 Your PAT is stored only in this browser tab's session memory. It is sent directly to api.github.com and nowhere else. Close this tab to clear it.

How to create a GitHub PAT
  1. Go to GitHub → Settings → Developer Settings → Personal access tokens → Fine-grained tokens
  2. Click Generate new token
  3. Set expiration (90 days recommended)
  4. Under Repository access, select Only select repositories and choose bobe-content-dashboard
  5. Under Permissions → Repository permissions, set Actions to Read and write
  6. Click Generate token and copy it
